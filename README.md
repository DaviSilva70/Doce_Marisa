## 📋 Sobre o Projeto

O **Marisa Doces** é uma landing page desenvolvida para uma confeitaria artesanal, apresentando seus produtos de forma visual e atrativa. O site oferece uma experiência moderna e responsiva, com foco em conversão de clientes através de pedidos via WhatsApp.

### 🎯 Objetivo

Criar uma presença digital profissional para o negócio de doces e bolos artesanais, facilitando o contato com clientes e destacando a qualidade dos produtos.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🎠 **Carrossel Interativo** | Apresentação dos produtos com Owl Carousel |
| 📱 **Layout Responsivo** | Adaptado para mobile, tablet e desktop |
| 💬 **Pedidos via WhatsApp** | Links diretos para facilitar o contato |
| 🧭 **Navegação Suave** | Scroll animado entre seções |
| 🔍 **SEO Otimizado** | Meta tags para melhor posicionamento |
| 🎨 **Design Moderno** | Interface limpa e profissional |

## 🚀 Como Executar

### Pré-requisitos

- Um navegador web moderno (Chrome, Firefox, Safari, Edge)

### Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/DaviSilva70/Doce_Marisa.git
   ```

2. **Acesse a pasta do projeto**
   ```bash
   cd Doce_Marisa/Doces_Marisa
   ```

3. **Abra o arquivo index.html**
   ```bash
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
   ```
